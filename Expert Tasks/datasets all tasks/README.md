# Dataset Folder - Expert Tasks

This folder contains the raw datasets used for the expert-level tasks.

### Datasets:

1. **`Consumer_Shopping_Trends_2026 (6).csv`**

   - **Records**: 11,789
   - **Focus**: Consumer behavior, shopping preferences, online vs store spending, tech savviness, demographics
   - **Used for**: Statistical analysis, segmentation, and hypothesis testing in Python
2. **`student_academic_placement_performance_dataset.csv`**

   - **Records**: ~5,000+ students
   - **Focus**: Academic performance, skills, internships, placement status, and salary packages
   - **Used for**: Power BI dashboard and placement insights
3. **`salary_data.csv`**

- **Records**: ~25,000+ professionals
- **Focus**: Skills, Degrees, Salary, Industry
- **Used for**: Predictive Model for predicting salary of individuals

These datasets represent real-world business scenarios for advanced analytics.

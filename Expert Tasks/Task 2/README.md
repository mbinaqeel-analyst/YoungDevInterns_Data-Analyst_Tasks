# Task 2: Power BI Dashboard & Insights

**Objective**: Create an interactive and professional dashboard for student placement analysis.

**Dataset**: Student Academic Placement Performance Dataset

**Dashboard Features**:

- Salary package distribution
- Academic performance vs placement correlation
- Impact of internships, skills, and extracurricular activities
- Filters by gender, city tier, and other dimensions

**Tools**: Power BI Desktop

**Output**: `Student Performance Report.pbix`

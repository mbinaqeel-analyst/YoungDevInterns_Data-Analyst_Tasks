# Expert Tasks - Data Analyst Internship @ YoungDev Interns

This repository contains the **Expert-Level Tasks** I completed during my Data Analyst Internship at **YoungDev Interns**.

These tasks focused on advanced statistical analysis, customer segmentation, hypothesis testing, and professional dashboarding using Python (NumPy) and Power BI.

### 🛠️ Tasks Completed

**Task 1: Advanced Analysis with Python**

- Performed deep statistical analysis on **Consumer Shopping Trends 2026** dataset (11,789 records)
- Implemented manual statistical techniques:
  - Descriptive statistics & 95% Confidence Intervals
  - Correlation, Regression, T-test, ANOVA, Chi-Square
  - K-Means Clustering for customer segmentation
  - High-Value Customer profiling & Wallet Share analysis
- **Output**: `Consumer_Shopping_Trends_Analysis.ipynb`

**Task 2: Power BI Dashboard & Insights**

- Built a comprehensive **Student Academic Placement Performance Dashboard**
- Analyzed placement status, salary packages, academic scores, skills, and extracurricular activities
- Created professional visualizations for stakeholders
- **Output**: `Student Performance Report.pbix`

**Task 3: End-to-End Machine Learning Salary Prediction System**

Developed a production-ready ML pipeline on 250,000 salary records:

- Robust sklearn Pipeline with ColumnTransformer (no data leakage)
- Trained & compared 5 models (Linear Regression → XGBoost)
- Hyperparameter tuning with RandomizedSearchCV
- Achieved **R² = 0.825**, MAE ≈ $11,974
- Built an interactive **Streamlit web app** for real-time salary predictions with confidence ranges and salary bands
- Added automated business insights and vectorized batch predictions

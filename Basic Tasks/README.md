# Basic Tasks - Data Analyst Internship @ YoungDev Interns

This repository contains the **3 foundational tasks** I completed as a **Data Analyst Intern** at **YoungDev Interns**.

### 📁 Folder Structure
- **`dataset/`** → Raw FIFA 21 player dataset (CSV)
- **`task1-clean-dataset/`** → Data cleaning (duplicates + missing values)
- **`task2-basic-charts/`** → Bar chart + Pie chart + Dashboard
- **`task3-basic-statistics/`** → Mean, Median, Mode, Standard Deviation

### 🛠️ Tasks Completed

**Task 1: Clean a Dataset**  
- Removed duplicates  
- Handled missing values  
- Standardized column names & data types  
- Added `Contract Status` column  
- **File**: `Cleaned Fifa Data.xlsx`

**Task 2: Create Basic Charts**  
- Built interactive Dashboard  
- Created Pie Chart (Contract Status)  
- Created Bar Chart (Preferred Foot distribution)  
- **File**: `Fifa Data With Charts.xlsx`

**Task 3: Perform Simple Calculations**  
- Calculated Mean, Median, Mode, and Standard Deviation for key metrics (Age, OVR, POT, Value, Wage, etc.)  
- **File**: `Fifa Data With Basic Statistics.xlsx`

### 🧰 Tools Used
- Microsoft Excel + Google Sheets
- Data cleaning, formulas, charts, and dashboarding

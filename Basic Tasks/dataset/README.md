# Dataset Folder

This folder contains the **raw dataset** used for all three basic tasks during my Data Analyst Internship at **YoungDev Interns**.

## 📁 File Information

**File Name:** `fifa21 raw data v2.csv`

**Description:**  
This is the original raw FIFA 21 player dataset containing information about **18,000+ football players**. It includes attributes such as player name, age, nationality, club, overall rating (OVA), potential, value, wage, positions, physical attributes, and more.

**Original Source:**  
FIFA 21 dataset (commonly used for data analysis practice)

**Size:** ~8.7 MB

## 📊 Dataset Overview

- **Total Rows:** 18,502 (including header)
- **Total Columns:** 77
- **Data Type:** CSV (Comma Separated Values)
- **Condition:** Raw & Messy (requires cleaning)

### Key Columns:
- `ID`, `Name`, `LongName`
- `Nationality`, `Age`, `Club`
- `OVA` (Overall Rating), `POT` (Potential)
- `Value`, `Wage`, `Release Clause`
- `Positions`, `Height`, `Weight`, `Preferred Foot`
- `Attacking`, `Skill`, `Movement`, `Power`, `Mentality`, `Defending`, `Goalkeeping` stats

## 🔧 Purpose

This raw file was used as input for:
- **Task 1**: Data Cleaning (removing duplicates, handling missing values, standardizing formats)
- **Task 2**: Data Visualization (Charts & Dashboard)
- **Task 3**: Statistical Analysis (Mean, Median, Mode, Standard Deviation)

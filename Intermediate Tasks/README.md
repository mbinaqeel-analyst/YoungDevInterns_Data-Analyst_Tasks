# Intermediate Tasks - Data Analyst Internship @ YoungDev Interns

This repository contains the **3 intermediate-level tasks** I completed during my Data Analyst Internship at **YoungDev Interns**.

### 📁 Folder Structure
- **`dataset/`** → Raw datasets (Sales, Fuel Prices, and Bike Shop Database)
- **`task1-pivot-tables/`** → Pivot Tables & Summary Reports
- **`task2-time-series-analysis/`** → Trend Analysis with Line Charts
- **`task3-sql-queries/`** → Advanced SQL Analysis on Bike Shop Database

### 🛠️ Tasks Completed

**Task 1: Build Pivot Tables**  
- Created dynamic pivot tables in Excel/Google Sheets from the sales dataset.  
- Analyzed revenue by Region, Category performance, Discount impact, and Payment methods.  
- **Output**: `Pivot_Tables_Summary.csv`

**Task 2: Analyze Trends Over Time**  
- Performed time-series analysis on Crude Oil Prices (1970–2026).  
- Visualized long-term price trends using line charts.  
- **Output**: Cleaned time series file + trend insights.

**Task 3: Use Basic SQL Queries**  
- Wrote 6+ practical SQL queries on a relational Bike Shop database (10 tables).  
- Analyzed Revenue, Store & Staff Performance, Customer Insights, Product Trends, and Operational Efficiency.  
- **Files**: Multiple `.sql` scripts with comments.

### 🧰 Tools Used
- Microsoft Excel / Google Sheets (Pivot Tables & Charts)
- SQL (MySQL / PostgreSQL compatible)
- Data Analysis & Visualization

# Dataset Folder - Intermediate Tasks

This folder contains all raw datasets used for the intermediate tasks.

### Files Included:

1. **`sales_dataset.csv`** - 50,000+ sales records (order details, region, category, revenue, discount, etc.)
2. **`fuel_prices_1970_2026.csv`** - Historical Crude Oil Prices (Monthly data from 1970 to 2026)
3. **Bike Shop Database (Relational)**:
   - `customers.csv`, `orders.csv`, `order_items.csv`
   - `products.csv`, `brands.csv`, `categories.csv`
   - `stores.csv`, `staffs.csv`, `stocks.csv`

These datasets were used to practice **Pivot Tables**, **Time Series Analysis**, and **SQL querying**.

**Note**: The bike shop data consists of 9 normalized tables simulating a real e-commerce database.
